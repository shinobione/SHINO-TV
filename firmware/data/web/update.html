Verified factory application — Ultra-V9.0.44

Generic firmware and filesystem update routes have been disabled in SHINO // TV.

The only proposed factory-return handler verifies the exact original manufacturer application image (494,144 bytes) against a build-pinned digest. No file upload or firmware write is offered from this standard interface.

This application update is not a full flash backup. It does not guarantee restoration of the original filesystem, settings or a device whose bootloader or application can no longer start.

In the standard build, factory-return writes are not compiled. The experimental return workflow requires a separately reviewed build and an explicit decision; do not upload files to undocumented endpoints.
